## Принятые решения и отступления

- Решения владельца D0–D11 действуют по умолчанию (бриф, раздел 4).
- **2026-10-10, указание владельца в сессии: «работай в main и все ветки с main смержи».**
  Это меняет D1 и §7 брифа:
  - работа идёт прямо в `main` форка, без ветки `Dev` и без PR по фазам;
  - отчёт фазы (бриф, §9.1) пишется файлом `docs/program/reports/phase-NN.md` и коммитится вместе
    с фазой — вместо описания PR; ссылка на отчёт и коммит — в таблице фаз;
  - ворота фазы прежние: `check`, `acceptance` (0 из 10), `upgrade:test` с фазы 2, пробы,
    независимое ревью диффа субагентом;
  - `Dev` (@ `8f647df`) больше не используется: всё, что в нём есть, уже в `main`.
- **Слияние веток 2026-10-10.** Из 37 веток форка в `main` не были слиты три:
  - `claude/zealous-hawking-v8n21d` — исследование 18 open-source проектов, только `docs/research/`;
    слита без конфликтов (`796412c`);
  - `claude/festive-fermi-til45k` — «галактика знаний» (`render_knowledge_galaxy`, `npm run galaxy`),
    44 файла, +5 046 строк; шесть конфликтов в документах (`bf2db78`). Её запись Д-82 столкнулась
    с Д-82 из `main`, а Д-85 … Д-108 зарезервированы брифом, поэтому она стала **Д-109**. После
    слияния сервер отдаёт **135 инструментов** (бриф писался при 134), профиль `memory` — 17;
  - `claude/new-session-gei6a4` — рабочая ветка этой сессии (бриф и журнал), `9ebccf1`.
  `npm run check` на слитом дереве: 1 293 теста, 0 упали, 16 пропущены; покрытие строк 97,29 %.
  `render_knowledge_galaxy` по MCP отработал: 3 292 звезды, 36 созвездий, HTML 1,18 МБ.
- **Следствие для критериев фазы 1:** в реестре 110 записей, а не 108 — Д-109 из слитой ветки и
  Д-110 (демо печатает число skills литералом), найденный ревью фазы 1. Галактика добавляет в
  `search_cli.py` команду `galaxy-export` — её тоже переносить на Node в фазах 3–4.

  - onnxruntime-node 1.30 не содержит сборки `darwin/x64` (в 1.21 была) — Intel Mac без локальной
    модели (Д-101, фаза 5);
  - дублированные ключи lockfile описывают вложенный onnxruntime-node 1.21.0, которого npm не
    ставит (Д-87, фаза 2);
  - без Python отказывают 10 из 13 поисковых инструментов, как в брифе; `embed_texts` без модели
    отказывает и с Python (Д-98).
- **Фаза 2 (2026-10-10), отступления:**
  - `.npmrc` пакета — `ignore-scripts=true`, а не `onnxruntime-node-install=skip`: npm 11 и 12
    предупреждают, что неизвестные ключи станут ошибкой; установочных скриптов в дереве два, оба не
    нужны;
  - CI ставит простым `npm ci`, а публикация образа (`docker-publish.yml`, джоб `publish`) — только
    из `stonebridgeway/ai-dev-system`: программа пушит в `main` форка, и без этого условия форк
    публиковал бы образ в свой GHCR. На форке Actions не стартуют вообще (джобы без раннера), так
    что опубликовано не было ничего — проверено по всем прогонам;

    подпадало под шаблоны `node --test` (Д-112);
  - `AI_DEV_HOME`, равный самому домашнему каталогу (в любом написании и через симлинк), сохраняет
    смысл 2.x — `~/.ai-dev`; для остальных значений D2 исполняется дословно;
  - Docker-часть теста обновления — сценарий в `docs/UPGRADE-TEST.md` плюс третий пользователь
    `upgrade:test` с окружением образа, без контейнера.

  моделью, все»** (перед этим: «некоторые для разработки вообще не нужны, к примеру андроид тв и
  оплата»; про Membrane — «пройтись по нему и посмотреть что нужно что нет»). Сделано отдельно от
  фаз, коммиты `0ff4737` … `768f9ee`:

    список — `docker/public-seed/03-skills-catalog/sources/external/membrane/CURATION.md`.
    Коннекторы, чья страница описывает другой продукт (ссылка на документацию или список сущностей
    чужие), убраны тоже. Коннектора «Android TV» в seed нет; игры и потребительские приложения
    вроде Dots! ушли;
  - остальные 154 skills (custom, ECC, taste-skill, Understand Anything и др.) оставлены все.
    Пограничный — `brandkit` (генерация брендбука): он встроен в цепочку frontend-дизайна
