   безопасности для 2.x (теги `v2.Y.Z` двигают только `:2`) и до какого срока?
3. **Д-318: Docker на Linux с uid не 1000.** Образ работает от uid 1000; на хосте с другим uid папка состояния не общая с
   хуками хоста (Д-322). Варианты: оставить и сказать (как сейчас), запускать с `--user $(id -u)` или собирать образ под uid
   пользователя.
4. **Подпись установщика (D7)**: сертификат или Azure Trusted Signing — какой путь и когда; без подписи SmartScreen
   предупреждает.
5. **Публикация npm (D4)**: публиковать 3.0.0 вместе с тегом или после ручной приёмки на трёх системах? Имя
   `ai-dev-system` свободно, но не закреплено: чем раньше публикация, тем меньше шанс, что его займут.
