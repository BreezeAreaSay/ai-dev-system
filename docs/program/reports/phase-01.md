### 6. Отступления и принятые решения

- **Работа в `main`, без PR и без `Dev`** — указание владельца 2026-10-10 («работай в main и все ветки
  с main смержи»). Отчёт фазы — этот файл вместо описания PR.
- **Слиты три ветки**, не слитые в `main`: исследование (`docs/research/`), галактика знаний и рабочая
  ветка сессии. Из-за галактики сервер отдаёт 135 инструментов, а не 134, как в брифе. Её Д-82
  столкнулся с Д-82 `main` и стал Д-109, потому что Д-85 … Д-108 заняты брифом.
- **В реестре 110 записей, а не 108:** Д-109 из ветки и Д-110 из ревью.
- **Д-101 дополнен находкой:** в onnxruntime-node 1.30 нет `darwin/x64` (в 1.21 был). На Intel Mac
  модель не загрузится — решение в фазе 5; тест-план macOS это уже говорит.
- **Д-87 дополнен находкой** (в запись войдёт с замером «после» в фазе 2): дублированные ключи
  описывают вложенный onnxruntime-node **1.21.0** с его зависимостями (`tar`, `global-agent` и
  другими), которого npm не ставит.
- **Д-106 подтверждён** (в брифе — «не перепроверено»).
- Размер схемы в документах — в байтах ответа `tools/list`, а не длина определений: так меряет
  бриф, и это то, что получает клиент.

### 7. Влияние на установки 2.x

Код не менялся, поведение установленных систем — тоже. Меняются только тексты: Python назван
обязательным, клиенты подключаются через `npm run clients:install`, для Codex и Claude Desktop из
клона описана ручная настройка. Действий от пользователя не требуется. Откат — `git revert`
коммитов фазы.
