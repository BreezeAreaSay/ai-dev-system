### 6. Отступления и принятые решения

1. **Подтверждение — у консоли и у трёх настроек.** Записи экранов (папка проектов, клиенты мастера, время простоя,
   автозапуск) идут по своей кнопке, без окна; зеркало модели, папка модели и профили — только после окна главного
   процесса (Д-288): с ними страница могла бы направить демон в сеть или сменить то, что получают агенты.
2. **Только-чтение — по слову демона** (`readOnlyHint`): консоль не спрашивает про инструмент, который демон помечает
   только читающим; список берётся один раз на сессию и для решения о проверках трея (Д-286).
3. **Консоль шлёт только аргументы из схемы** инструмента (у всех 148 схемы закрыты): лишнее имя — отказ (Д-287).
4. **Окно подтверждения**: строки по 48 знаков с отступом, не больше 36 строк аргументов — иначе отказ с объяснением
   (Д-292); значение длиннее 240 знаков обрезается с пометкой о полной длине.
5. **Сессия приложения — `all,control`** при любой настройке `profiles`: экраны читают инструментами агента, консоли
   нужны все.
6. **Язык — в шапке**, не на «Настройках»; `settings_set` со страницы язык не меняет.
7. **Пределы списков**: 50 задач и решений, 20 передач, 10 эпиков, 20 совпадений поиска — с пометкой, когда есть ещё.
8. **Вид ответа консоли** (читаемо или JSON) — выбор человека, держится, пока приложение открыто (Д-291).
9. **Тесты фазы 10 после слияния**: id прямых вызовов — `call-…` (Д-257), запрещённая странице настройка — язык, а не
   зеркало (`b990f12`).
10. **Раздел эпиков** при сбое одного `epic_status` показывает ошибку всего раздела с «Повторить» (подозрение ревью,
    не воспроизведено) — оставлено.
