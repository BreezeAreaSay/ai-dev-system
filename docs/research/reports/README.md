# Raw research notes

Working notes behind [../open-source-research-2026-09.md](../open-source-research-2026-09.md),
kept because the summary cites them and a reader checking a claim needs the
measurement it came from. Written 15 September 2026, in English.

Two kinds of file:

| Prefix | What it holds |
| --- | --- |
| `aidev-*` | The state of this repository at the time of the review: context and search, memory, lifecycle and verification, tool surface and observability — with `file:line` references and measured response sizes. |
| `ref-*` | Implementation notes on the external projects that were read, each ending with portable ideas, what was judged too heavy, and the attribution a port would need. |

These are notes, not documentation. They describe the code as it was on
`main` at commit `c67b00c`; the repository moves, they do not. Where a note and
the current code disagree, the code is right.

External repositories were read at their default branch on 15 September 2026.
Every project is named with its licence in the summary's attribution table; no
third-party code was copied into this repository.
